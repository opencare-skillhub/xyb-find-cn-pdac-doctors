原始混合 CSV 标注 222 位医生，现行医生表已有后续补录；两者数量不同不应通过删除补录来“对齐”。`source_胰腺癌医生数据库_2026-10-16.csv` 和 `imaging-readers_2026-10-16.md` 保留为历史来源，不作为可直接查询的规范表。
