# CSV 查询与维护规范

## 数据入口

默认只读取技能目录内 `data/doctors.csv` 或 `data/trials.csv`，更新 CSV 后即时生效。
`data/source_*.csv` 和影像 Markdown 是历史来源快照，不参与查询，不自动覆盖现行 CSV。

先查询医生/试验数据库文件，基于命中项及用户后续问题再使用辅助搜索技能；条件变化时重新查库，不以历史导出结果代替当前 CSV。需要最新状态时查库后直接继续核验；仅离线查库时不强制开展外部检索。
`--db PATH` 可显式读取其他同结构 CSV 或 SQLite；SQLite 仅供兼容，表名由 `--table` 指定，不是维护入口。

从技能根目录执行；任意工作目录也可使用脚本绝对路径：

```bash
python3 scripts/doctor_db.py --name 钱黎俊
python3 scripts/doctor_db.py --city 太原 --dept 肿瘤
python3 scripts/doctor_db.py --query "上海 胰腺"
python3 scripts/doctor_db.py --table trials --query KRAS --json
python3 scripts/doctor_db.py --list --json
```

默认输出完整编号 list；`--brief` 是同义兼容选项；`--json` 返回所有字段和 `count`。没有分页和 limit，备注不截断。`--query` 用空格分词、跨所有字段 AND 匹配，不做自然语言/同义词推断。字段搜索是包含匹配，`--name` 是精确匹配。自然语言请求应转为准确条件；不要把“上海的影像医生”整句交给关键词搜索。`--list` 不与筛选条件混用。

## 医生表

保持现有全部中文表头，必填：`序号、姓名、医院、科室、城市、来源日期、关键依据`。

- `序号`：稳定唯一，新行取当前最大值加一；不因排序重编号。
- `医院、科室、城市`：写完整名，明确院区；不确定的院区在备注注明待核，不伪造出诊安排。
- `区域、大类、角色定位、主要用途`：描述诊疗用途；社区提供的任职注明性质。
- `ABC分类`：A 内科主诊、B 特定用途、C 暂不纳入/待核、支撑（影像等）。补录未核实可为 C，备注解释“待核非否定”。
- `风险状态`：R0 原筛查未记录问题，R1 风险线索待复核，RU 经验待核。不能当作评级或疗效保证。
- `A/6、B/4、C1/2、C2/2、D/2、E/2、F/2、已核实P、覆盖K/20`：保留原模型数据；没有证据不补分，不以总分排名。
- `未知项、候选结论、辅助治疗标签、备注`：保留不确定性；评价注明用户/社区提供及日期。
- `关键依据`：优先官方 URL 和简短摘要；暂时仅有用户资料时标明资料名及仓库内摘要位置。不要只写“官网”而不留可追溯信息。
- `来源日期`：本行资料新增或复核日期，YYYY-MM-DD；历史事实的日期、核实范围另写备注，不能把所有旧信息标成今日已核实。

同一医生同一医院/科室修改原行，不重复新增。同名不同人保留独立记录及身份依据。跨院区记录须明确区分。

## 试验表

保持现有 15 个中文表头，必填 `序号、试验编号、药物/方案、医院/中心、城市、来源`。来源写注册页 URL 和核验日期；状态注明日期。一个登记号可覆盖多个中心，不能仅凭报道推断招募中或适合患者。

## 临床试验来源快照

`data/source_胰腺癌临床试验库_2026-10-16.csv` 为用户于 2026-10-17 提供的独立试验库原件，保留首行 `#` 说明。去掉首行说明后，36 条记录、15 列与 `data/trials.csv` 逐字段一致，因此仅登记来源，不重复追加。默认查询继续读取规范化的 `data/trials.csv`。原件不直接传给 `--db`：该文件含说明行，不是首行为表头的规范查询 CSV。

后续导入更新时先解析真实表头，再比对已有记录；有正式登记号时按登记号和研究方案识别，描述性编号需结合药物、期别、中心等核对，不能只按药名合并不同试验，也不能只按序号追加。保留旧资料出处，冲突注明待核，不能将文件生成日期视为当次招募核验日期。

## 提交检查

CSV 使用 UTF-8（兼容 BOM），用表格软件或 Python csv 模块编辑；逗号、引号及换行按 CSV 规范转义。不要直接把混合表头的原始来源快照当成查询库。

```bash
python3 scripts/doctor_db.py --validate
python3 scripts/doctor_db.py --table trials --validate
python3 scripts/doctor_db.py --audit > /tmp/doctor-audit.json
```

校验检查字段、必填、日期、重复序号与医生身份；不验证临床事实。`--audit` 输出完整待复核记录，不截断备注；试验当前状态须逐项核查。失败返回非零退出码并输出原因。
